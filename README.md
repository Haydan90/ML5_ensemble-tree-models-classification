# ML5: Ансамбли и деревья решений (от нуля до CatBoost/XGBoost) (`ML5_ensemble-tree-models-classification`)

Пятый проект трека Machine Learning в Школе 21 посвящен глубокому изучению древовидных алгоритмов. В работе реализованы классические модели **с нуля на чистом NumPy** (дерево решений, случайный лес, градиентный бустинг), а также проведено тестирование современных библиотек бустинга на датасете **Kaggle: [Don't Get Kicked](https://www.kaggle.com/c/DontGetKicked)**.

---

## 1. Содержание и структура проекта

1. **Подготовка и кодирование данных:**
   - Временной сплит (`Time-based Split`) по дате покупки (`PurchDate`) для предотвращения утечки данных из будущего.
   - Предобработка признаков через пайплайны (`scikit-learn`, `CountEncoder` для категориальных признаков).
2. **Алгоритмы с нуля (`From Scratch` на NumPy):**
   - `MyDecisionTreeClassifier` / `MyDecisionTreeRegressor` (поиск оптимальных разделений по критерию Джини и среднеквадратичной ошибке).
   - `MyRandomForestClassifier` (бэггинг, случайные подмножества признаков `max_features`).
   - `MyGBDTClassifier` (градиентный бустинг над логистической функцией потерь с использованием деревьев регрессии в качестве базовых алгоритмов).
3. **Современные библиотеки градиентного бустинга:**
   - `LightGBM` (leaf-wise рост деревьев, гистограммный алгоритм).
   - `XGBoost` (оптимизация второго порядка с гессианами, регуляризация).
   - `CatBoost` (нативная работа с категориальными признаками, упорядоченный бустинг).

---

## 2. Анализ результатов и выводы по моделям

- **Кастомные алгоритмы:** Собственная реализация дерева решений показала конкурентный результат на валидации (`Gini = 0.2925` против `0.2831` у стандартного `sklearn.DecisionTreeClassifier`), подтверждая корректность написанной логики сплитов. Тем не менее, кастомные решения уступают библиотечным в скорости работы из-за отсутствия низкоуровневой оптимизации на C++.
- **Ансамблирование:** Переход от одиночного дерева к случайному лесу (`MyRandomForestClassifier`, `Gini = 0.3243`) и градиентному бустингу (`MyGBDTClassifier`, `Gini = 0.3344`) закономерно улучшил качество классификации.
- **Сравнение библиотек бустинга:**
  - На этапе валидации лучшие результаты показали `XGBoost` (`0.3688`) и `LightGBM` (`0.3620`).
  - На **тестовом наборе** наилучшую стабильность и генерализацию продемонстрировал `CatBoost` (`Gini = 0.3693`), показав меньший разрыв между метриками.
  - Все модели демонстрируют склонность к переобучению (значения Gini на обучающей выборке существенно выше валидационных и тестовых), что типично для бустингов глубоких деревьев на табличных датасетах без жесткой регуляризации.

## 5. Как запустить проект

1. Клонировать репозиторий:
   ```bash
   git clone [https://github.com/Haydan90/ML5_ensemble-tree-models-classification.git](https://github.com/Haydan90/ML5_ensemble-tree-models-classification.git)
   cd ML5_ensemble-tree-models-classification
   ```
2. Скачать датасет с официальной страницы [Kaggle: Don't Get Kicked](https://www.kaggle.com/c/DontGetKicked) и положить файл `training.csv` в папку `data/`.
3. Установить зависимости:
   ```bash
   pip install numpy pandas scipy scikit-learn category_encoders lightgbm xgboost catboost jupyter
   ```
4. Запустить Jupyter Notebook:
   ```bash
   jupyter notebook
   ```
